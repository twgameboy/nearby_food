# NearbyFood V3.2｜Dual Data Engine
主引擎：Geoapify Places API（API Key）
第二引擎：OpenStreetMap / Overpass
第三層：Last Good 最近成功資料

第一次使用：到 Geoapify 建立免費 API Key，開啟 App 後貼到 API Key 欄位並儲存，再按「定位搜尋」。
Key 僅儲存在該瀏覽器 localStorage。公開部署建議在 Geoapify 控制台限制網站 Origin / HTTP Referrer。

GitHub Pages：將 ZIP 內所有檔案覆蓋 repository 根目錄並 Commit。
